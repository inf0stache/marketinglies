ML-VS · Verification Status

Anyone can claim anything.
The stamp means we checked.

The MarketingLies Verification Standard (ML-VS) is the verification process behind the Protected by MarketingLies stamp. It's modeled on SOC 2: a defined set of controls, evidence collected on a continuous basis, and an attestation that maps each claim on your site to the artifact that backs it. If you can't produce the evidence, you don't get the stamp.

QN
Quantitative Claims
Numbers must be reproducible
"10,000+ users" → query + timestamp
CP
Comparative Claims
Benchmarks must be cited
"Faster than X" → methodology link
CR
Credential Claims
Certs must be current
"SOC 2 compliant" → report date
CA
Capability Claims
Features must actually ship
"AI-powered" → describe the model
SO
Social Proof
Logos require permission
"Trusted by X" → written consent
TS
Testimonials
Quotes must be attributable
Real person, real title, real quote
01 — Submit
Connect your site. ML-VS extracts every quantitative, comparative, credential, and capability claim.
02 — Provide Evidence
For each claim, upload the source: a query, a benchmark, a cert, a screenshot, a signed release.
03 — Continuous Monitoring
Site changes are diffed. New claims surface in the pipeline. Stale evidence flags itself.
04 — Earn the Stamp
If everything checks out, the stamp goes live. If a claim breaks, the stamp is suspended automatically.
